# ✦ StyleSwap

### AI-Powered Personal Stylist

StyleSwap is an AI-powered personal styling assistant that helps users create outfit ideas from the clothes they already own.

Instead of buying new clothes, StyleSwap analyzes your wardrobe and generates personalized outfit combinations based on your:

- Occasion
- Personal style
- Weather
- Available wardrobe

## ✨ Features

- 📸 Upload multiple clothing images
- 🤖 AI-powered wardrobe analysis
- 👗 Generate 3 personalized outfit looks
- 🎯 Occasion-based styling
- 🌤️ Weather-aware recommendations
- 💡 Styling tips for every outfit
- ❤️ Save your favorite looks
- 🔄 Regenerate new outfit combinations
- 📱 Responsive interface

## 🧠 AI Technology

StyleSwap uses:

- **Qwen/Qwen3-VL-8B-Instruct**
- **Hugging Face Inference API**
- **Featherless AI**
- **Streamlit**
- **Python**

The vision-language model analyzes uploaded clothing images and generates outfit recommendations based on the user's preferences.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Application logic |
| Streamlit | Web interface |
| Hugging Face | AI inference |
| Qwen3-VL | Image and text understanding |
| Featherless AI | Inference provider |
